# 子午花信 V2 身体记录与观心趋势分析 PRD

版本：V2.0 草案  
适用范围：首页「案台」身体记录模块、身体日志详情页、「观心」页面身体趋势分析  
目标使用方：Codex / Claude Code / Minimax / 产品与研发协作  
当前状态：需求收敛版，可进入技术方案拆解与实现评估

---

# 1. 产品背景

## 1.1 V1 当前定位

「子午花信」V1 已具备东方养生修习打卡能力，核心功能包括：

- 首页「案台」展示当前时辰、今日修习进度、今日应修习惯。
- 「修习」页管理用户已添加的养生习惯和修习策略。
- 「观心」页展示修习报表，包括周报、月报、年报、完成率、累计修习、坚持时日、最长连日、习惯日历等。
- 「归藏」页承载用户资料、设置和数据相关入口。

V1 的核心问题是：它主要回答“我今天有没有修习”“我修习得怎么样”，但还没有系统回答：

> 我今天身体怎么样？  
> 我的睡眠、情绪、精力、身体感觉有什么变化？  
> 我做了修习之后，身体有没有被我看见？

## 1.2 V2 升级方向

V2 产品定位调整为：

> 身体记录工具 + 东方养生修习辅助。

即：身体记录成为产品主线，东方养生修习成为用户照顾身体的行动辅助。

V2.0 先完成身体记录和近 7 天身体趋势，不做复杂健康分析、不做医疗诊断、不做体质判断。

---

# 2. V2.0 产品目标

## 2.1 用户目标

帮助用户低负担记录自己的身体状态：

- 昨晚睡得怎么样
- 今天情绪如何
- 今天整体精力怎么样
- 身体哪里最有感觉
- 有没有饮食、排便、冷暖、出汗、女性周期、其他不适等身体线索
- 最近 7 天身体状态有没有反复出现的模式

用户不需要每天强制记录，也不需要一次填写完整，只需要留下当天最明显的身体线索。

## 2.2 产品目标

V2.0 需要完成：

1. 首页增加「今日身体记录」模块。
2. 支持首页快速记录睡眠、情绪、精力、身体感觉。
3. 支持进入身体日志详情页，记录更多身体线索。
4. 支持最近 7 天日期切换和编辑。
5. 支持模块级保存，不要求整页统一提交。
6. 支持轻量女性周期记录。
7. 「观心」页面增加身体趋势 Tab。
8. 身体趋势先只看近 7 天。
9. 所有趋势模块统一采用「近 7 天小趋势 + 身体观察」结构。
10. 后台保留结构化数据，为后续身体趋势、AI 摘要、修习关联分析预留基础。

# 3. V2.0 非目标范围

V2.0 暂不做：

- 医疗诊断
- 疾病判断
- 体质判断
- AI 医生
- 备孕、排卵预测、完整经期健康 App
- 复杂长期身体档案
- 月度身体趋势
- 年度身体趋势
- 修习与身体变化的自动关联分析
- 身体状态到修习动作的推荐
- 身体记录完成率
- 漏记提醒
- 补记惩罚
- 排行榜、社交比较、健康评分

禁止出现以下表达：

```text
你属于某体质
你可能患有某疾病
某症状说明你有某问题
某修习可以治疗某问题
你需要治疗
```

允许使用以下表达：

```text
这是一条身体线索
可以继续观察
最近反复出现
更常被记录到
如果持续明显不舒服，建议及时休息，必要时咨询专业人士
```



# 5. 首页「案台」身体记录模块

## 5.1 首页模块顺序

V2 首页案台顺序为：

```text
当前时辰卡

今日身体记录                         更多
[睡眠]    [情绪]
[精力]    [身体感觉]

今日修习
最多展示 12 个今日应修习惯
```

说明：

- 身体记录在今日修习之前。
- 今日修习继续保留 V1 首页最多展示 12 个今日应修习惯的规则。
- 若今日应修习惯超过 12 个，沿用 V1 原有提示逻辑，引导用户进入修习页调整频次或减少任务。

## 5.2 「今日身体记录」模块结构

模块包含：

```text
标题：今日身体记录
右侧入口：更多
四张卡片：睡眠 / 情绪 / 精力 / 身体感觉
```

点击规则：

```text
点击睡眠卡片 → 打开睡眠底部弹窗
点击情绪卡片 → 打开情绪底部弹窗
点击精力卡片 → 打开精力底部弹窗
点击身体感觉卡片 → 打开身体感觉底部弹窗
点击更多 → 进入身体日志详情页
```

## 5.3 首页卡片状态

首页身体记录卡片只做两种状态：

```text
未记录
已记录
```

不展示：

```text
部分记录
补记
漏记
完成率
待同步
同步失败
保存失败
今日已更新
```

## 5.4 首页卡片未记录状态

展示：

```text
图标
模块名
去记录
```

示例：

```text
睡眠
去记录
```

## 5.5 首页卡片已记录状态

展示：

```text
图标
模块名
今日摘要
```

示例：

```text
睡眠
睡得浅

情绪
紧绷

精力
疲惫

身体感觉
肩颈紧
```

## 5.6 首页摘要规则

| 模块 | 首页摘要规则 |
|---|---|
| 睡眠 | 优先显示第一个睡眠标签；没有标签时显示入睡-醒来时间 |
| 情绪 | 显示主情绪 |
| 精力 | 优先显示精力标签；没有标签时显示评分 |
| 身体感觉 | 显示第一条主身体感觉，格式为「部位 + 感受」 |

## 5.7 首页记录范围

首页只展示和编辑今天的身体记录。

不在首页提供近 7 天日期切换。

近 7 天切换只放在身体日志详情页。

# 6. 身体日志详情页

## 6.1 入口

从首页「今日身体记录」标题右侧「更多」进入。

## 6.2 页面定位

首页 = 快速记录  
身体日志详情页 = 完整补充  
观心 = 趋势回看

身体日志详情页不负责趋势分析，只负责查看和编辑最近 7 天内某一天的身体日志。

## 6.3 页面结构

```text
最近 7 天日期 Tab

常用记录
- 睡眠
- 情绪
- 精力
- 身体感觉

更多身体线索
- 饮食与胃口
- 排便
- 冷暖
- 出汗
- 女性周期
- 其他不适补充
```

## 6.4 最近 7 天日期 Tab

规则：

- 从左到右按时间递增。
- 最右为今天。
- 默认进入页面时选中今天。
- 不按自然周展示。
- 不做完整日历。
- 不显示已记录小圆点。
- 不显示补记标识。
- 不显示漏记状态。
- 不显示完成率。
- 不显示额外页面标题，如「今日身体日志」「昨天身体日志」「补记身体日志」。

示例：

```text
6/14｜6/15｜6/16｜6/17｜前天｜昨天｜今天
```

用户点击某日期后，下方模块内容直接切换为该日期的身体日志。

## 6.5 页面标题规则

身体日志详情页不额外显示日期标题。

原因：

- 日期 Tab 的选中态已经表达当前正在查看哪一天。
- 下方模块内容已能直观看出是否记录。
- 不增加“今日 / 昨天 / 补记”的概念，避免任务感。

## 6.6 模块展示方式

详情页全部模块都展示，但不展开完整表单。

每个模块以卡片摘要形式展示：

```text
模块名
摘要 / 还没有记录
去记录 / 编辑
```

示例：

```text
睡眠
睡得浅｜多梦｜23:40-06:30
编辑
```

未记录示例：

```text
情绪
还没有记录
去记录
```

## 6.7 普通模块状态

普通模块只有两种状态：

```text
未记录
已记录
```

## 6.8 女性周期模块状态

女性周期模块有特殊状态：

```text
未开启
未在经期
经期中
```

## 6.9 模块点击交互

点击任意模块卡片，打开对应底部弹窗编辑。

保存后：

1. 底部弹窗关闭。
2. 保存该模块数据。
3. 刷新当前日期模块摘要。
4. 若当前日期是今天，并且首页对应卡片可见，则首页摘要同步刷新。
5. 显示轻提示「已保存」。

# 7. 身体日志保存规则

## 7.1 模块级保存

身体日志采用模块级保存，不设置整页统一保存按钮。

规则：

```text
用户编辑哪个模块，就保存哪个模块。
任意模块保存成功后，即生成或更新对应日期的身体日志。
用户不需要填写完整页面。
每个模块可以单独修改。
每个模块可以单独清空。
```

## 7.2 生成身体日志条件

当用户在任意模块保存了有效内容时，系统自动生成对应日期的身体日志。

有效内容示例：

```text
睡眠：选择了标签，或填写了入睡/醒来时间，或填写备注
情绪：选择主情绪，或填写备注
精力：填写评分，或选择标签，或填写备注
身体感觉：至少有一条 bodyPart + feeling
饮食与胃口：任意标签、胃口、饭后感受或备注
排便：选择有/无，或填写其他字段
冷暖：选择整体冷暖、局部标签或备注
出汗：选择标签或备注
女性周期：开启周期、进入经期、结束经期或记录经期感受
其他不适：选择标签或填写自由输入
```

## 7.3 清空规则

用户可以清空单个模块内容。

清空后：

```text
该模块回到未记录状态。
如果该日期仍有其他模块内容，身体日志继续存在。
如果该日期所有模块都被清空，则删除该日期 BodyDailyLog。
```

## 7.4 用户端不显示补记

用户可以编辑最近 7 天内任意日期，但用户端不显示「补记」。

后台可通过：

```text
recordDate
createdAt
updatedAt
```

判断是否为非当天创建，用于后续分析权重或数据审计。

# 12. 身体趋势统一表达结构

所有趋势模块统一采用：

```text
近 7 天小趋势 + 身体观察
```

## 12.1 小趋势

作用：

```text
展示最近 7 天每日记录摘要。
```

格式：

```text
日期
当日摘要
```

示例：

```text
6/14
睡得浅

6/15
多梦

6/16
-

昨天
醒后累

今天
一般
```

没有记录时显示：

```text
-
```

不要显示：

```text
未记录
漏记
缺失
```

## 12.2 身体观察

作用：

```text
基于近 7 天内反复出现的标签、状态、部位、评分，生成一段温和观察。
```

统一语气：

```text
反复出现
被记录到
出现得比较多
可以继续观察
可能值得留意
```

禁止语气：

```text
说明你
导致你
证明你
你存在
你属于
你需要治疗
```

## 12.3 触发规则

统一规则：

```text
近 7 天内，该模块记录 ≥ 2 天，才生成身体观察。
同一标签 / 同一状态 / 同一部位 / 同一组合出现 ≥ 2 次，才进入观察文字。
如果记录 0-1 天，只展示小趋势和记录不足提示。
如果记录比较分散，不强行分析。
```

记录不足提示：

```text
这几天记录还不多。
再多留下几天记录后，会更容易看见变化。
```

记录分散提示：

```text
这几天的记录比较分散，暂时还看不出特别反复出现的身体线索。
可以继续保持记录。
```

谨慎提醒模板：

```text
如果这种不舒服持续明显，建议及时休息，必要时咨询专业人士。
```

```text
昨天 胃腹胀
今天 头痛
```

如果某天记录多条身体感觉，小趋势只展示第 1 条主身体感觉。

## 17.3 身体观察分析内容

分析：

```text
高频部位
高频感受
高频「部位 + 感受」组合
level 是否反复偏高
```

部位：

```text
头
眼
肩颈
胸口
胃腹
小腹
腰
腿
手脚
全身
其他
```

感受：

```text
痛
胀
酸
麻
紧
冷
热
沉
干
堵
无力
```

程度：

```text
1 轻微
2 有感觉
3 明显
4 较重
5 很不舒服
```

观察示例：

```text
近 7 天，你记录了 4 天身体感觉。
「肩颈紧」被反复记录到。
可以继续观察：肩颈紧出现的日子，是否也更容易伴随眼干或精力下降。
```

高频部位示例：

```text
这几天，身体感觉主要集中在肩颈和眼部。
可以继续观察：长时间用电脑后，这些部位是否更容易有感觉。
```

程度偏高示例：

```text
这几天，有几次身体感觉程度达到 4 分以上。
如果持续明显不舒服，建议及时休息，必要时咨询专业人士。
```

## 17.4 触发规则补充

```text
同一部位出现 ≥ 2 次，可以进入观察。
同一「部位 + 感受」组合出现 ≥ 2 次，优先进入观察。
level ≥ 4 出现 ≥ 2 次，可以触发谨慎提醒。
```

## 17.5 暂不分析

```text
不判断疼痛原因
不判断身体部位病理风险
不做疾病推断
```

## 18.5 身体观察分析内容

后台分别分析各子模块，但前台只输出一段综合观察。

可分析内容包括：

### 饮食与胃口

```text
油腻、辛辣、生冷、夜宵、漏餐、吃太多是否反复出现
饭后胀、反酸、困、恶心、胃痛是否反复出现
胃口偏弱或吃一点就饱是否反复出现
```

观察示例：

```text

```

### 排便

```text
未排是否反复出现

```

```text
这几天，「费力」或「偏干」被反复记录到。

```

### 冷暖

```text
怕冷、怕热是否反复出现
手脚凉、小腹冷、腰冷是否反复出现
脸热、上火感是否反复出现
```

观察示例：

```text
这几天，「怕冷」和「手脚凉」出现得比较多。
可以继续观察：睡眠、经期或天气变化时，冷暖感是否更明显。
```

### 出汗

```text
不太出汗是否反复出现
稍动就出汗是否反复出现
夜间出汗是否反复出现
出汗后舒服或更累是否反复出现
```

观察示例：

```text
这几天，「稍动就出汗」被记录到不止一次。
可以继续观察：出汗后身体是更舒服，还是更容易疲惫。
```

### 女性周期

```text
经期第几天
痛经是否明显
疲惫、腰酸、小腹冷痛等伴随感受是否出现
经期和精力、情绪、身体感觉是否可能有关联
```

观察示例：

```text
这几天处在经期中，「疲惫」和「小腹冷痛」被记录到。
可以继续观察：经期前后，精力和情绪是否会有明显变化。
```

### 其他不适

```text
头痛、胸闷、心慌、恶心、口干、喉咙不适、皮肤痒、水肿、注意力散、头脑发沉等是否反复出现
```

观察示例：

```text
这几天，「头脑发沉」被记录到不止一次。
可以继续观察：头脑发沉出现的日子，睡眠和精力状态是否也有变化。
```

对于胸闷、心慌：

```text
如果这类不适持续明显，建议及时休息，必要时咨询专业人士。
```

# 21. 同步与异常处理

## 21.1 本地优先

保存身体记录时：

```text
先本地保存
页面即时刷新
网络可用时同步云端
网络不可用时保留 pending 状态
网络恢复后自动同步
```

## 21.2 用户端状态展示

首页不展示同步状态。

身体日志详情页也不需要默认展示同步状态，除非本地保存失败。

如果本地保存失败：

```text
保存失败，请稍后重试
```

如果本地保存成功但云端同步失败：

```text
不阻断用户继续记录
可在后台保留待同步状态
必要时在非阻断位置提示
```

## 21.3 数据恢复

用户清空缓存、换设备登录或重新进入小程序时：

```text
恢复用户资料
恢复身体日志最近 7 天数据
恢复女性周期状态
恢复首页今日身体记录摘要
恢复观心身体趋势视图所需数据
```

## 21.4 隐私

身体日志包含睡眠、情绪、身体感觉、女性周期等敏感信息。

要求：

```text
数据仅归属当前用户
分享路径不携带个人身体记录数据
用户后续应可删除身体日志
女性周期必须由用户主动开启
```

# 25. 最终产品原则

V2.0 身体记录和身体趋势分析应遵循以下原则：

```text
低负担
不强迫
不惩罚
不制造焦虑
不做诊断
不做因果判断
让用户看见身体，而不是管理身体
```

核心体验目标：

```text
今天身体怎么样，可以轻轻记一下。
最近身体有什么变化，可以慢慢看见。
```

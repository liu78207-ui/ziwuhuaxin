# 打卡云函数 - 数据库索引配置

## 重复打卡防御机制

为了防止重复打卡，需要在云开发控制台的数据库中创建联合唯一索引。

## 索引配置步骤

1. 登录微信开发者工具
2. 点击"云开发"按钮进入云开发控制台
3. 选择"数据库"标签
4. 找到 `checkin_logs` 集合
5. 点击"索引"标签
6. 点击"添加索引"

## 索引配置

### 联合唯一索引

```json
{
  "name": "unique_openid_habit_date",
  "unique": true,
  "keys": {
    "_openid": 1,
    "habit_id": 1,
    "checkin_date": 1
  }
}
```

### 字段说明

- `_openid`: 用户唯一标识（自动写入）
- `habit_id`: 习惯ID
- `checkin_date`: 打卡日期，格式为 `YYYY-MM-DD`

## 防御层级

本系统采用三层防御机制防止重复打卡：

### 第一层：前端防抖
- 按钮点击后禁用1秒
- 防止用户快速重复点击

### 第二层：本地校验
- 本地存储中检查是否已存在今日记录
- 避免重复创建本地记录

### 第三层：云端唯一索引
- 数据库层面的联合唯一索引
- 即使前两层都失效，数据库也会拒绝重复写入

## 错误处理

当唯一索引冲突时，云函数会返回：
```json
{
  "success": false,
  "message": "今日已打卡"
}
```

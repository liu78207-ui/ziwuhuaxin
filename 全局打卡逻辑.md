## 三、打卡完整业务流程

### 3.1 什么是"打卡"？

**打卡的通俗理解**：就像上班签到一样，你告诉系统"我今天做了这件事"。

### 3.2 打卡做了什么？

当你点击习惯卡片上的打卡按钮时，系统做了以下事情：

```
┌─────────────────────────────────────────────────────────────────────┐
│                        打卡做了什么？                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  第1步：页面变脸                                                      │
│  ─────────                                                            │
│  你看到卡片从"未打卡"变成"已打卡"的样子                               │
│                                                                      │
│  第2步：本地记录                                                      │
│  ─────────                                                            │
│  手机记住："我在XX习惯上于2026年5月3日打卡了"                          │
│                                                                      │
│  第3步：云端备份                                                      │
│  ─────────                                                            │
│  把这个记录也存到云端服务器，这样换手机也能看到                        │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.4 取消打卡做了什么？

如果你误点了打卡，可以再次点击取消：

```
步骤1：你再次点击已打卡的按钮
        │
        ▼

        │
        ▼

        │
        ▼
步骤4：同步到云端删除记录
        │
        ▼
步骤5：显示"取消成功"
```

### 3.6 连续打卡天数怎么算的？

**连续打卡天数** = 从今天（或昨天）往前数，有多少天是连续打卡的

```
举例：
假设今天是5月6日，你的喝茶习惯打卡记录如下：

日历：  5月1日  5月2日  5月3日  5月4日  5月5日  5月6日
       ──────  ──────  ──────  ──────  ──────  ──────
喝茶：   ✓      ✓      ✗      ✓      ✓      ○(今天)
               ↓                         ↓
              断开                       现在连续

连续天数计算：
• 5月6日还没打卡
• 5月5日打了卡 ✓ → 开始计数
• 5月4日打了卡 ✓ → 连续第1天
• 5月3日没打卡 → 中断了！

所以连续天数 = 2天（5月4日和5月5日）
```

## 九、异常处理机制

### 9.1 什么是"异常处理"？

就是防止出问题、出问题了怎么办。

### 9.2 常见问题1：重复打卡

**问题**：用户手滑点了两下，或者网络慢多点了几次

**解决方法**：

```
第1下点击：系统检查 → 发现没打过 → 允许打卡 ✅
第2下点击：系统检查 → 发现已经打过了 → 拒绝打卡 ❌
         ↓
    显示提示："今日已打卡"
```

**代码层面的检查**：
```javascript
// 系统会检查今天的打卡记录里有没有这条记录
// 如果已经有了，就不再添加，直接返回"今日已打卡"
```

### 9.3 常见问题2：网络不好

**问题**：手机网络断了，打卡记录没传到云端

**解决方法**：

```
正常情况：
  本地记录 ✅ → 云端记录 ✅ → 显示成功

网络断了：
  本地记录 ✅ → 云端记录 ❌ → 本地先存着
  
网络恢复后：
  （目前设计）本地记录保留，但云端需要用户重新操作
```

### 9.4 常见问题3：数据丢失

**问题**：手机坏了或者清除了缓存

**解决方法**：

```
系统启动时会检查：
1. 本地有没有习惯数据？
   有 → 读取到手机上
   
2. 没有本地数据，但云端有？
   → 从云端拉取数据到本地
```

### 9.5 常见问题4：取消打卡失败

**场景**：你今天打过卡了，想取消，但网络不好

**系统检查**：
```
1. 检查今天有没有打卡记录
   没有 → 提示"今日未打卡，无需取消"

2. 有记录 → 执行删除操作
```

## 十一、首页"已坚持多少天"计算逻辑

### 11.1 位置

首页每个习惯卡片上显示的"🔥 X天"，就是"已坚持多少天"。

### 11.2 计算规则

**从今天（或昨天）往前数，连续有多少天打卡了？**

```
规则说明：
┌─────────────────────────────────────────────────────────────────────┐
│                                                                      │
│  起点规则：                                                          │
│  ───────                                                            │
│  • 今天打了卡 → 从今天开始往前数                                      │
│  • 今天没打卡 → 从昨天开始往前数                                      │
│                                                                      │
│  连续规则：                                                          │
│  ───────                                                            │
│  • 连续打了卡 → 继续数                                                │
│  • 中间断了1天 → 停止计数                                            │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 11.3 举例说明

**情况1：今天打了卡**
```
假设今天是5月6日，打卡记录如下：

日历：  5月4日  5月5日  5月6日
       ──────  ──────  ──────
喝茶：   ✓      ✓      ✓

计算过程：
• 今天(5月6日)打了卡 → 起点是今天
• 往前数：5月6日 ✓ → 第1天
• 继续数：5月5日 ✓ → 第2天
• 继续数：5月4日 ✓ → 第3天
• 再往前(5月3日)没记录 → 停止

显示：🔥 3天
```

**情况2：今天没打卡，断了**
```
假设今天是5月6日，打卡记录如下：

日历：  5月3日  5月4日  5月5日  5月6日
       ──────  ──────  ──────  ──────
喝茶：   ✓      ✗      ✓      ○(今天没打)

计算过程：
• 今天没打卡，看昨天
• 昨天(5月5日)打了卡 → 起点是昨天
• 往前数：5月5日 ✓ → 第1天
• 继续数：5月4日 ✗ → 断了！停止

显示：🔥 1天
```

**情况3：完全断了**
```
假设今天是5月6日，打卡记录如下：

日历：  5月1日  5月2日  5月3日  5月4日  5月5日  5月6日
       ──────  ──────  ──────  ──────  ──────  ──────
喝茶：   ✗      ✗      ✗      ✗      ✗      ○(今天没打)

计算过程：
• 今天没打卡，看昨天
• 昨天(5月5日)也没打卡
• 再往前(5月4日)也没打卡
• 一直到5月1日都没有 → 连续天数为0

显示：🔥 0天
```

### 11.4 代码逻辑（简化版）

```javascript
function 计算连续天数(打卡记录列表) {
    // 1. 按日期降序排列
    const 所有日期 = 打卡记录列表.map(r => r.date).sort((a,b) => b - a)
    
    // 2. 确定起点
    const 今天 = new Date().toISOString().split('T')[0]
    const 昨天 = new Date(Date.now()-86400000).toISOString().split('T')[0]
    
    let 起点 = null
    if (所有日期包含(今天)) {
        起点 = 今天
    } else if (所有日期包含(昨天)) {
        起点 = 昨天
    } else {
        return 0  // 没有起点，返回0
    }
    
    // 3. 从起点往前数
    let 连续天数 = 0
    for (let i = 0; i <= 所有日期.length; i++) {
        const 当前日期 = 起点 - i天
        if (所有日期包含(当前日期)) {
            连续天数++
        } else {
            break  // 断了就停止
        }
    }
    
    return 连续天数
}
```

## 十二、"观心"页面统计计算逻辑

"观心"页面是看统计数据的页面，有几个重要的统计指标：

### 12.1 打卡完成率

**什么是打卡完成率？**

完成率 = 实际打卡次数 ÷ 应该打卡的次数 × 100%

```
举例说明：
┌─────────────────────────────────────────────────────────────────────┐
│                                                                      │
│  假设本周（7天）你有2个习惯                                           │
│                                                                      │
│  习惯A：每天都要做                                                    │
│  习惯B：隔天做一次                                                    │
│                                                                      │
│  应该打卡的次数：                                                    │
│  • 习惯A：7天 × 1次/天 = 7次                                          │
│  • 习惯B：7天 ÷ 2 = 3.5次 ≈ 4次（取整）                               │
│  • 总计：7 + 4 = 11次                                                │
│                                                                      │
│  实际打卡次数：假设你打卡了8次                                        │
│                                                                      │
│  完成率 = 8 ÷ 11 × 100% ≈ 73%                                        │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 12.2 累计xiuxi（修习次数）

**什么是"累计xiuxi"？**

就是你在这个时间段里，总共打卡了多少次。

```
计算方式：把所有打卡的记录全部加在一起

举例：
本周打卡记录：
• 习惯A：5月1日、5月2日、5月3日、5月5日 → 4次
• 习惯B：5月1日、5月3日、5月5日 → 3次
• 习惯C：5月2日、5月4日 → 2次

累计xiuxi = 4 + 3 + 2 = 9次
```

### 12.3 坚持日的计算天数

**什么是"坚持日"？**

坚持日 = 一周里有几天你至少打了一个卡

│  周二      ✗       ✓       ✗       ✓ 有                              │
│  周三      ✓       ✓       ✗       ✓ 有                              │

### 12.4 最长连日的计算逻辑

**什么是"最长连日"？**

在一段时间内，连续打卡最多的天数（所有习惯合起来看）。

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                      │
│  计算规则：                                                          │
│  ───────                                                            │
│  1. 把"有没有打卡"看成是1，没有看成是0                                │
│  2. 找出最长的连续1的串                                               │
│                                                                      │
│  举例：                                                              │
│  假设一周7天，每天的打卡情况：                                        │
│                                                                      │
│  周一  周二  周三  周四  周五  周六  周日                             │
│  ────  ────  ────  ────  ────  ────  ────                            │
│   ✓     ✓     ✗     ✓     ✓     ✗     ✓                             │
│   1     1     0     1     1     0     1                             │
│          ↕                                                        │
│         连续2天           连续2天           只有1天                    │
│                                                                      │
│  最长连日 = 2天                                                      │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

**复杂情况举例：**
```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                      │
│  假设一周7天，打卡情况：                                              │
│                                                                      │
│  周一  周二  周三  周四  周五  周六  周日                             │
│  ────  ────  ────  ────  ────  ────  ────                            │
│   ✓     ✓     ✓     ✓     ✗     ✓     ✓                             │
│   1     1     1     1     0     1     1                             │
│   └───┘                                                               │
│     连续4天           │        └──┘                                  │
│                      │         连续2天                               │
│              这里断了                                                  │
│                                                                      │
│  最长连日 = 4天（周一到周四）                                         │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 12.6 已删除习惯的特殊处理

如果某个习惯被删除了，统计时只计算删除日期之前的数据：

```
举例：
• 习惯A在周三被删除了
• 周一、周二、周三、周四、周五、周六、周日
• 只有周一、周二计入统计（因为周三是删除当天，不算）
```

## 附录：关键术语解释

| 术语 | 通俗解释 |
|------|---------|
| **MyHabits** | 存放你设置的习惯，比如"每天喝茶"、"每周跑步" |
| **CheckinLogs** | 存放每次打卡的时间记录，就像签到本 |
| **云函数** | 运行在云端服务器上的代码，负责处理数据 |
| **本地存储** | 手机上的数据存储，断网也能访问 |
| **openid** | 微信分配给每个用户的唯一ID，用于区分是谁的数据 |
| **连续打卡天数** | 从最近一次打卡往前数，连续打卡的天数 |
| **打卡完成率** | 实际打卡次数 ÷ 应该打卡的次数，反映完成目标的比例 |
| **累计xiuxi** | 统计时间段内所有打卡次数的总和 |
| **坚持日** | 有打卡的天数（去重），一周7天里有多少天打了卡 |
| **最长连日** | 连续打卡最长的天数，看你最多能坚持几天不间断 |
